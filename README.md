# svix
Approximately implements Ian Martin's SVIX model to compute the expected return from option prices.

i made this in January of this year and never uploaded it here lol
to change the stock just go in the code and change "spy" to whatever you want, but ideally the stock you pick should have a liquid options market
doesn't usually work on weekends cuz of yfinance not working or smth

Please check out Ian Martin's awesome 2 papers here:
1) https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2771464 (the one for an individual stock)
2) https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2772101 (the one for the overall market)
